# datamart.help

Placeholder site: one `index.html`, served by a small Bun server (`server.ts`) so it fits
the dev2 deploy kit (a Docker container behind nginx, `/healthz` for the health check).

Deploys to dev2 on every push to `main` (`.github/workflows/deploy-dev2.yml`, generated by
cli-tools `dev2/dev2-site`). Run locally: `bun server.ts`.
